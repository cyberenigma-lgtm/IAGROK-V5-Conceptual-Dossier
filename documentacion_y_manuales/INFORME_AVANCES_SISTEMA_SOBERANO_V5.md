## ⚡ 2. MOTOR DE SABIDURÍA SOBERANA JIT (`motor_sabiduria_soberana.py`)
- **Indexador Hot-RAM:** Mantiene un índice invertido en RAM ultrarrápida sin depender de bases de datos externas de terceros.
- **Normalizador Accent-Insensitive (`_normalizar`):** Procesa términos independientemente de tildes o mayúsculas (ej. *"termodinámica"* == *"termodinamica"*).
- **Latencia de Consulta:** **< 0.05 ms** para emparejamiento directo y síntesis semántica.

- **`devorar_tema_web(tema, lobulo)`**: Realiza búsquedas directas y vía `opensearch` en Wikipedia / APIs abiertas, limpia HTML superfluo y absorbe el texto para el lóbulo indicado.
- **`devorar_url_para_lobulo(url, lobulo)`**: Descarga cualquier manual o documento público desde una URL web.
- **Protección Anti Rate-Limit:** Incorpora pausas de cortesía y encabezados HTTP adaptativos para evitar bloqueos HTTP 429.

## 🌐 5. ENDPOINTS REST INTEGRADOS EN `app.py`
Se han expuesto las siguientes APIs en el backend Flask de IAGROK:

- **`GET /api/sabiduria/stats`**: Retorna el número de documentos, categorías y conceptos en Hot-RAM del disco `E:\`.
- **`POST /api/sabiduria/asimilar`**: Asimila e indexa cualquier documento en tiempo real.
- **`GET /api/lobulos/stats`**: Devuelve la telemetría de distribución por lóbulos cerebrales.
- **`POST /api/lobulos/devorar`**: Endpoint unificado que permite enviar un `lenguaje`, un `contenido`, una `url` o un `tema_web` para ser devorado e indexado por un lóbulo específico.
- **`POST /api/neurobus7/pensar`**: Razonamiento central integrando las respuestas de la Biblioteca de Sabiduría Soberana.
